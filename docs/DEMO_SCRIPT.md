## Flow
1. Admin creates officer.
2. Officer logs in.
3. Officer opens case.
4. Upload `Forensic_Report.pdf`.
5. Show SHA-256.
6. Show audit event.
7. Run AI classification/entity extraction/summary.
8. Search for the document.
9. Officer B attempts access.
10. Show `ACCESS DENIED`.
11. Create Version 2.
12. Show version history.
13. Modify a controlled copy.
14. Show `TAMPER DETECTED`.
15. Show audit chain.
16. Show evidence custody.

## Closing
The system provides secure access, centralized case documents, versioning, integrity verification, tamper-evident auditability, evidence traceability and AI-assisted understanding/retrieval.
